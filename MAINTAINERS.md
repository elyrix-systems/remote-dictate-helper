# Maintainers

Repository organization: [Elyrix Systems](https://github.com/elyrix-systems).

**Primary maintainer: [@pradaev](https://github.com/pradaev).**

The primary maintainer reviews contributions, decides project scope, merges pull
requests and prepares releases. Changes anywhere in the repository request their
review through `.github/CODEOWNERS`.

Only `@pradaev` may merge or push to `main`. The branch's update allowlist contains
that account alone, with no teams or apps; protection also applies to admins.
CI checks remain required. The primary maintainer has a personal exception to
the PR-review requirement so they can maintain their own changes without a
second maintainer. External contributors submit pull requests and cannot merge.
